# 8장: 클린 아키텍처로 구현하는 테스트 패턴

## 장 코드 발췌
이 장에 등장하는 코드 스니펫은 `chapter_code_excerpts` 폴더에 등장 순서대로 정리되어 있다. 예시: `00_error_class.py`
이 코드들은 참고용이며 실행을 위한 것이 아니다.

## 작업 관리 애플리케이션

이 장에서는 클린 아키텍처의 명시적 경계와 관심사 분리가 어떻게 포괄적인 테스트 전략을 자연스럽게 가능하게 하는지 살펴본다. 작업 관리 시스템을 예제로 사용하여, 클린 아키텍처의 구조가 다양한 유형의 테스트를 어떻게 지원하고 테스트를 더 관리하기 쉽고 의미 있게 만드는지 확인한다.


## 테스트 실행

저장소의 [README](../README.md) 섹션의 지침에 따라 환경을 설정했는지 확인한다.

pytest를 사용하여 모든 테스트를 실행한다:
```bash
cd Chapter_8/TodoApp
pytest
```

테스트를 병렬로 실행한다:
```bash
# pytest-xdist가 설치되어 있는지 확인
pytest -n auto
```

테스트를 무작위 순서로 실행한다:
```bash
# pytest-random-order가 설치되어 있는지 확인
pytest --random-order
```
